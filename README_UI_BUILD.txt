Project Platypus — Tauri UI source bundle
=========================================

This archive contains everything needed to compile the Tauri desktop UI.
Build artifacts (node_modules/, target/, dist/) are intentionally excluded —
they are regenerated by the package managers during the build.

Layout (keep these as SIBLING directories — the Rust path-dependencies, the
Vite alias, and the bundle script all rely on the relative paths between them):

  ui-react/                 React frontend + Tauri backend (src-tauri/)
  rust/                     Native analysis workspace (project_platypus_native +
                            platypus-* crates). Required: ui-react/src-tauri
                            depends on it via `path = "../../rust"`. Also builds
                            the `platypus` Python module (rust/pyproject.toml).
  packages/activity-viewer/ Local package consumed by the UI through the Vite/
                            tsconfig alias `@platypus/activity-viewer`
                            (-> ../packages/activity-viewer/src).
  scripts/bundle-python.sh  Assembles a relocatable Python + the `platypus`
                            module for bundling into the app (see below).
  samples/*.apk             Sample APKs to open in the app.

Prerequisites
-------------
  * Node.js (18+) and npm
  * Rust toolchain (rustup, stable)
  * Tauri v2 system prerequisites for your OS:
    https://v2.tauri.app/start/prerequisites/
  * A C toolchain (for native crate compilation)

Build & run
-----------
  # Install deps in BOTH the app and the local activity-viewer package.
  # The UI imports `@platypus/activity-viewer` from its SOURCE (see the Vite
  # alias), and that package resolves react/@types/react from its OWN
  # node_modules — so `npm run tauri build` (which runs `tsc`) fails with
  # "cannot find module 'react'" if this second install is skipped. (Plain
  # `npm run tauri dev` happens to work without it, which is misleading.)
  ( cd packages/activity-viewer && npm install )
  cd ui-react
  npm install
  npm run tauri dev          # run in development
  # or
  npm run tauri build        # produce a packaged desktop binary

Scripting (Python) — optional but recommended
----------------------------------------------
The Script panel runs Python and uses a compiled `platypus` extension module.
At runtime the backend resolves the interpreter in this order:
  1. $PLATYPUS_PYTHON / $PLATYPUS_RUFF env override
  2. a Python BUNDLED into the app at resources/python/ (see below)
  3. the system `python3` / `ruff` on PATH

To bundle a self-contained Python so scripting works with no user setup, run
ONCE PER TARGET PLATFORM before `npm run tauri build`:

  ./scripts/bundle-python.sh        # downloads a relocatable CPython, builds
                                    # the platypus wheel, installs it + ruff

This populates ui-react/src-tauri/resources/python/, which tauri.conf.json
already ships via `bundle.resources`. If you skip it, the app still builds and
falls back to a system `python3` (scripting just requires the user to have
python3 + the platypus wheel installed).

Notes
-----
  * `npm run tauri build` runs `npm run build` (tsc + vite) for the frontend,
    then compiles the Rust backend (which pulls in the sibling `rust/` crates).
  * Cargo.lock and package-lock.json are included for reproducible builds.
  * The bundled interpreter itself is NOT in this archive (it's platform- and
    Python-ABI-specific); generate it per platform with bundle-python.sh.
  * No external paths outside this bundle are required (the `harness-loader`
    dependency was removed).
